Nightfall City

An experimental 3D open-world browser game.

Nightfall City is a browser-based 3D game prototype inspired by the freedom and exploration of open-world games.

The project has been under development for approximately two months using OpenAI Codex and was recently published on GitHub.


## Project Features

The current prototype includes systems and interfaces for world exploration, district selection, vehicles, NPC interactions, missions, an in-game economy, vehicle trading, camera controls, and locally saved gameplay progress.

## Technologies

The published browser build uses HTML, CSS, JavaScript, and Three.js/WebGL.

## How to Run

1. Download or clone this repository.
2. Place the downloaded files together in a folder.
3. Open a terminal in that folder.
4. Run the following command:

`python3 -m http.server 8000`

5. Open your browser and visit:

`http://localhost:8000/README.html`

Python 3 is required for this local-server method.

## Development Status

Nightfall City is an actively developed prototype, not a finished commercial game.

The initial GitHub upload contains a bundled HTML build. The original modular development files have not yet been published.

Future work includes gameplay improvements, realistic 3D asset integration, performance optimization, and project documentation.

Project Goal

To explore accessible, browser-based 3D game development and progressively build a reusable example of interactive open-world gameplay.

This project is independently developed and is not affiliated with Rockstar Games.
